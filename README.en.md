# Aralar Thesis — Pastoral diagnosis by remote sensing

[![License: CC BY-NC-ND 4.0](https://img.shields.io/badge/License-CC%20BY--NC--ND%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by-nc-nd/4.0/)
[![Status](https://img.shields.io/badge/status-in%20progress-yellow.svg)]()

Integrated pipeline for the pastoral diagnosis of the Aralar Natural Park (SAC ES2120011) using Sentinel-2 remote sensing, GAM climate modelling and a fourfold triangulation of the Pastoral Pressure Index (PPI).

**Bachelor's thesis**, Degree in Geography and Spatial Planning, UPV/EHU. Developed within the LIFE Oreka Mendian project (LIFE15 NAT/ES/000762).

> **Project website**: https://moxkix.github.io/ARALAR_TFG/
>
> **Documentation**: the `docs/` folder is published on the website automatically. Any file uploaded there (Word, PDF, CSV, etc.) appears as a card in the Documents section without touching the HTML.

---

## Summary

This thesis diagnoses pastoral pressure in the subalpine grasslands of Aralar using Sentinel-2 LAI series inverted with PROSAIL-NN, modelled climatically with GAM and validated by **four independent strategies** between 2018 and 2025. The most original approach is **Strategy D** (beech-forest reference), which uses the adjacent climax forest cover as a climate thermometer to isolate the pastoral signal from the climatic one.

### Main results

- **Quasi-biennial pattern**: pastoral crises in 2020, 2022 and 2025 alternating with relaxation in 2023 (4/4 concordance among the four strategies).
- **Spatial gradient consistent** with the distance to the shepherd huts: near > intermediate > remote grassland.
- **G6 climate model** validated by LOYO (leave-one-year-out) over the 2018-2025 series.
- **Operational diagnosis** for the adaptive monitoring of LIFE Oreka Mendian.

### PROSAIL web-app (Sentinel-2 inversion)

The application in `scripts/python/web-app/` is a FastAPI server with a bundled frontend. It lets you interactively configure the LUT parameters (PROSAIL ranges, solar geometry, sampling distribution, noise), generate it in memory with the real PROSPECT-D + 4SAIL model and run the inversion on Sentinel-2 images (SNAP BEAM-DIMAP or 10-band GeoTIFF) by minimum distance with cKDTree.

```bash
cd scripts/python/web-app
python -m venv venv && source venv/bin/activate     # Windows: venv\Scripts\activate
pip install -r requirements.txt
python main.py
# Open http://localhost:8000
```

The final products (exported LUTs and neural-network coefficients ready to inject into GEE) are versioned in `data/coefficients/`. The runtime cache (`temp_prosail/`) is excluded from the repository.

### Cartographic products per year

Each `maps/<year>/` folder contains the following PNG maps (naming `aralar_mapa_*_<year>.png` / `aralar_pastos_mapa_*_<year>.png`), together with the GeoTIFFs (`.tif`) of each variable:

| Family | Maps |
|---|---|
| PPI triangulation | `IPP_A_pastos`, `IPP_A_todos`, `IPP_B_pastos`, `IPP_C_pastos` |
| Synthesis | `IPP_consenso_pastos`, `IPP_concordancia_pastos`, `IPP_espacializado` |
| Management | `mapa_biomasa`, `mapa_calidad`, `mapa_carga`, `mapa_balance`, `mapa_riesgo` |
| Control | `mapa_pendiente` |

**Strategy D** is integrated into the diagnosis and the triangulation figure, but it is not exported as a standalone spatial map. An `aralar_resumen_<year>.txt` with the year's metadata is also generated.

## How to reproduce

### Requirements

- **Python 3.10+** with: `prosail`, `scikit-learn`, `numpy`, `rasterio`, `matplotlib`, `pandas`
- **R 4.3+** with: `mgcv`, `SPEI`, `ggplot2`, `dplyr`, `tidyr`, `lubridate`
- An active **Google Earth Engine account**

### Pipeline steps

**1. LUTs and neural-network training (local Python)**

```bash
# LUT generation with the web-app (web interface at localhost:8000)
cd scripts/python/web-app
pip install -r requirements.txt
python main.py

# NN training on the exported LUTs and export of coefficients for GEE
cd ../
python train_gee_coefficients.py
```

The exported LUTs and final coefficients are stored in `data/coefficients/`.

**2. Large-scale inversion in GEE (JavaScript)**

Upload the Aralar assets to the GEE project (boundary, HIC, shepherd huts, DEM5).
Paste `scripts/javascripts/GEE_Pipeline_Integrado_Aralar.js` into the code editor and run it. The exports to Drive include the zonal LAI CSVs, the climate CSVs and the yearly GeoTIFFs.

> ⚠️ **Documented critical bug**: in the zonal reduction, the `ee.Dictionary.combine()` calls must take `false` as the second argument (overwrite=false). Without this precaution, the defaults overwrite the real values and the exported CSV comes out entirely as -9999.

**3. Climate modelling and the four PPI strategies (R)**

```r
source("scripts/R/diagnostico_pastoral_aralar_v9_4.R")
```

Output: `data/diagnostico_pastoral.csv`, `data/validacion_loyo.csv`, `data/comparacion_modelos.csv` and the diagnosis figures in `figures/` (charts and report in Basque).

**4. Pastoral cartography (Python)**

```bash
cd scripts/python
python cartografia_pastoral_v5.py --year 2022
```

Or run `scripts/batch/ejecutar_cartografia5.bat` to process the full 2018-2025 series. Output in `maps/<year>/` (maps with titles and legends in Basque).

## Project website

The website (`index.html` + `style.css`) is published with GitHub Pages from the `main` branch and the repository root. It is **trilingual (Basque / Spanish / English)** with a selector in the header; the choice is remembered in the browser. The listing of the Documents and Charts sections is built when the page loads by querying the GitHub API (`/repos/Moxkix/ARALAR_TFG/contents/{docs,figures}`). This means that **simply uploading a file to those folders is enough for it to appear**, without touching the HTML.
